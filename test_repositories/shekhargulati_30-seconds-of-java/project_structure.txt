# Directory Explanations:
# src/          : Source code (implement src/snippets.py for tests to pass)
# tests/        : All original translated test cases (from src/test/java/...Tests.java)
# public_tests/ : All public translated test cases (from ...PublicTests.java)
# requirements.txt : Declares pytest dependency
# run_tests.sh  : Bash script to run all tests using pytest

# Usage Instructions:
# 1. Install dependencies: `pip install -r requirements.txt`
# 2. Implement all methods in src/snippets.py as per the original Java Snippets API.
# 3. Run all tests (original and public) by executing: `./run_tests.sh`
# 4. To run only original tests:    pytest tests/
# 5. To run only public tests:      pytest public_tests/
