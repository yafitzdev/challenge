Directory explanations:
- src/: All source code modules (adapted from the Java source).
- src/methodoverloading/: Contains main function and class implementations.
- tests/original/: All translated original tests from Java's original tests.
- public_tests/: All translated public tests from Java's public tests.
- requirements.txt: Lists required dependencies (pytest).
- run_tests.sh: Runs all tests (both original and public) with a single command.
- project_structure.txt: This file.

How to run tests:
1. Install dependencies: `pip install -r requirements.txt`
2. Run all tests: `./run_tests.sh` (ensure executable permission with `chmod +x run_tests.sh`)

Notes:
- Both original and public tests are discovered and run by pytest automatically.
- Source files mimic the original Java class names and methods as closely as possible.
- No placeholder or incomplete test code; all logic and assertions are fully translated from Java.
