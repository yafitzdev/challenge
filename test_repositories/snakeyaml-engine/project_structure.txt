Contract: the tests do `from src.snakeyaml_engine import iter_events` and iterate over iter_events(yaml).
It must yield the parser events one by one, each as the string the Java test helper
EventRepresentation (src/test/.../external_test_suite/EventRepresentation.java) produces, for exactly the
events the Java low-level parser (new Parse(LoadSettings.builder().build()).parseString(yaml)) produces.
Where the Java library raises an error, iter_events must raise an exception after yielding the same events
the Java library yielded before its error. The inputs come from the YAML test suite (its data is not
provided). 40 of 402 cases are public in public_tests/; the remaining 362 are hidden.
Use the Python standard library only; no third-party packages are installed when the tests run.
