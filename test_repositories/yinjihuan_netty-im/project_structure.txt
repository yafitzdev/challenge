Explanations:
- src/nettyim/: Stubs/minimal implementations for all classes under test (so tests can run)
- tests/original/: Python translations of all original (private) Java tests
- public_tests/: Python translations of all public Java tests
- __init__.py: Included in all packages to ensure importability
- requirements.txt: All Python dependencies
- run_tests.sh: Runs all tests simply via 'pytest'
- README.md: Details on how to set up and run tests.
