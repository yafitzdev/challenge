# Directory explanations:
# - src/smsradar: All implementation code, stubs provided only as needed for test execution.
# - tests/original: Full translation of all original Java test logic, using pytest conventions.
# - public_tests: Public subset of tests with slightly different data/coverage as per Java public tests.
# - requirements.txt: Python dependencies. Install with 'pip install -r requirements.txt'.
# - run_tests.sh: Single-command test runner for all tests (original+public) using pytest.
# To run all tests:  pip install -r requirements.txt && ./run_tests.sh
