Directory / File explanations:
- `src/bluetoothlegatt/`: Minimal code needed so all translated test cases run.
- `tests/original/`: Original Java test translations; mirrors all logic and edge cases.
- `public_tests/`: Public and edge/public tests.
- `run_tests.sh`: Runs *all* tests (pytest discovers both test trees).
- `requirements.txt`: All required Python dependencies.
- `README.md`: Describes structure and usage.
-------------------------------------------------------
Setup & Run:
$ pip install -r requirements.txt
$ ./run_tests.sh
